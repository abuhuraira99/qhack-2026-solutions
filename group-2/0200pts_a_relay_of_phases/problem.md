## Challenge Statement

Instantaneous Quantum Polynomial-time (IQP) circuits are a family of quantum circuits built from mutually commuting gates. Despite their relatively simple structure, IQP circuits are believed to be difficult to simulate classically in general and provide an interesting setting for studying quantum optimization.

In this challenge, you will construct and optimize an IQP circuit from scratch.

An IQP circuit's operator representation can be written as

$$
U(\boldsymbol{\theta})
=
\prod_{j}
\exp\left(
-\frac{i\theta_j}{2}X_{S_j}
\right),
$$

where

$$
X_{S_j} = \prod_{k\in S_j} X_k
$$

is a tensor product of Pauli-$X$ operators acting on a subset $S_j$ of the qubits.

For example, the pattern

```python
pattern = [
    [[0], [1]],
    [[1, 2]],
    [[0, 2], [1, 3]]
]
```

defines three parameters. The first parameter is shared by rotations generated by $X_0$ and $X_1$, the second by $X_1X_2$, and the third by $X_0X_2$ and $X_1X_3$. Thus,

$$
U(\boldsymbol{\theta})
=
e^{-i\theta_0X_0/2}
e^{-i\theta_0X_1/2}
e^{-i\theta_1X_1X_2/2}
e^{-i\theta_2X_0X_2/2}
e^{-i\theta_2X_1X_3/2}.
$$

Because all of the generators contain only Pauli-$X$ operators, these rotations commute.

The measurement at the end of the circuit is specified by a collection of Pauli-$Z$ observables. Each observable is represented by a binary vector

$$
\mathbf a=(a_0,\ldots,a_{n-1}),
$$

corresponding to

$$
Z_{\mathbf a}
=
\prod_{k=0}^{n-1}Z_k^{a_k}.
$$

For example,

```python
observable = [1, 0, 1, 0]
```

represents the observable

$$
Z_0Z_2
$$

and 

```python
observable = [1, 1, 0, 1]
```
represents the observable

$$
Z_0Z_1Z_3.
$$

Your goal is to build a circuit given a `pattern` and `observable` and find the IQP parameters $\boldsymbol{\theta}$ that minimize the total expectation value

$$
C(\boldsymbol{\theta})
=
\sum_{\mathbf a\in\mathcal A}
\langle 0|
U^\dagger(\boldsymbol{\theta})
Z_{\mathbf a}
U(\boldsymbol{\theta})
|0\rangle.
$$

## Challenge Code

Construct the IQP circuit given a `pattern` of rotation gates, the respective `weights` (i.e. parameters), and an `observable`. Your `iqp_circuit` must be a QNode that takes in the following:

- `weights` (`np.array(float)`): The weights or parameters of the circuit, as described above. 

-  `pattern` (`np.array`): The pattern of the rotations as described above. The $i$-th element of `weights` is the rotation parameters for the gates encoded in the $i$-th element of `pattern`.

- `observable` (`np.array(int)`): The array describing the observable, as described above.

The QNode `iqp_circuit` should return the expectation value of the given `observable`. The number of parameters is determined by the length of `pattern`, while the number of qubits will be fixed to be equal to four (`n_qubits = 4`).


Construct the `iqp_circuit` using PennyLane operations. You should **not** use `qp.IQP`. Additionally, remember that **the challenge system does not allow the import of any additional libraries** than the ones given. 

Having built the circuit, and starting from an initial set of parameters, use your circuit as a cost function to build a function `optimize_iqp`, which finds the weights that minimize $C(\boldsymbol{\theta})$, and return these optimized parameters. This function takes in the `pattern` and `observable` and return an `np.array` of optimized weights.

For example,

```python
pattern = [
    [[0], [1]],
    [[1, 2]],
    [[0, 2], [1, 3]]
]

observables = [0, 1, 0,1]

params = optimize_iqp(pattern, observables)
```

should return parameters that prepare an IQP state that minimizes

$$
\langle Z_0Z_2\rangle.
$$

## Challenge Statement

The Hamiltonian $H$ of a quantum system is the observable that measures its total energy. A surprising result in physics is that we can use this operator to calculate how a given quantum system evolves in time. An initial state $\vert \psi\rangle$ will, after a time $t$, evolve into $U(t)\vert \psi\rangle,$ where

$$ 
U(t) = \mathcal{T}\exp(-iHt)
$$

 is a unitary operator. The symbol $\mathcal{T}\textrm{exp}$ denotes the time-ordered matrix exponential, which isn't easy to calculate. However, there's no need for you to do it—PennyLane to the rescue!

 In this challenge, we deal with the Nuclear Magnetic Resonance (NMR) Hamiltonian, which models a spin subject to an external oscillating magnetic field. It is given by 

$$
H_{NMR} = B_0 Z + B_1(\cos(\omega t)X - \sin(\omega t)Y),
$$

where $B_0$ and $B_1$ are the parallel and transversal components of the magnetic field and $\omega$ is the oscillation frequency of the field. 

In this challenge, you are asked to evolve an initial spin state $\vert 0 \rangle$ via the unitary evolution generated by this Hamiltonian. You can achieve this using [qp.evolve](https://docs.pennylane.ai/en/stable/code/api/pennylane.evolve.html). The Hamiltonian is time-dependent, so the documentation in [qp.pulse.PamaetrizedHamiltonian](https://docs.pennylane.ai/en/stable/code/api/pennylane.pulse.ParametrizedHamiltonian.html) may also be useful for you. After evolving the state, you should return the computational basis probabilities.
